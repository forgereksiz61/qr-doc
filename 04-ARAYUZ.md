# İlk arayüz — görmeden genişletme

## Sadece tek ekran

- Başlık: `Rapor Görüntüleyici`.
- Sade açık arka plan, temiz tipografi, Türkçe ifadeler, Tailwind CSS.
- PDF belge alanı: responsive `iframe`, erişilebilir `title`.
- `PDF'yi yeni sekmede aç` bağlantısı: telefonların dahili PDF davranışı için yedek.
- 404 ekranı: `Rapor bulunamadı.`
- Hata durumu: teknik hata ayrıntısı göstermeyen mesaj.

## Şimdilik ekleme

Admin paneli, dosya yükleme formu, ziyaretçi listesi, kurum logosu, rapor doğrulandı rozeti, animasyonlar, karmaşık PDF.js araç çubuğu, dashboard ve navigasyon menüsü.

## Kontrol

320 px mobil genişlikte yatay kaydırma olmasın. iPhone/Android PDF embed farklı davranabilir; yeni sekme bağlantısı kalmalı. `iframe` yerleşimi makul ekran yüksekliğinde olmalı.
